UKRmol+ Tools
=============

Jakub Benda (c) 2025


### Information

Helper scripts and programs based on UKRmol+.

 - polarizability.f90: Evaluates the static or dynamic dipole polarizability of a molecule
   given cdenprop outputs.
 - Hrabitt.f90: Calculates exact two-photon delays for RABITT ionization of hydrogen atom.
 - build-ukrmolp.sh: Builds a Linux shell installer of UKRmol+ with all dependencies.
 - build-ukrmolp-mingw64.sh: Builds a Windows binary distribution of UKRmol+.
